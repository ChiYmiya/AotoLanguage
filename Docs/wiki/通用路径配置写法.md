# Node.js 路径处理

## path.join()

### 函数签名

```ts
path.join(...paths: string[]): string
```

### 输入

多个路径字符串。

```ts
path.join(__dirname, "../language/Zh-CN.json")
```

### 输出

一个规范的完整路径。

例如：

```
E:\github\AotoLanguage\language\Zh-CN.json
```

---

## 参数说明

### __dirname

当前脚本所在目录。

例如：

```
E:\github\AotoLanguage\scripts
```

---

### ../

返回上一层目录。

例如：

```
scripts
    │
    ▼
AotoLanguage
```

---

###

不是拼接。

只是函数参数分隔符。

真正负责拼接的是：

```ts
path.join()
```

---

## 为什么推荐 path.join()

优点：

- 自动适配 Windows（`\`）和 Linux（`/`）路径分隔符。
- 不依赖 `process.cwd()`（当前工作目录）。
- 本地、GitHub Actions、Linux、Windows 都能正常工作。
- 可读性更高，不需要手动拼接字符串。
